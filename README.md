# مغامرات خباب ويقين

موسم الخريف بعالم أيلاف: خريطة متفرعة فوق لوحة القلعة، حكايات تنلعب باختيارات تغيّر الطريق، قصر أزياء، غرفة دفتر ورسم، وألعاب ثنائية تنلعب من جهازين.

## التشغيل

الموقع ملفات ثابتة (HTML/CSS/JS) بدون خطوة بناء.

**أسهل طريقة (الموقع + اللعب عن بعد بخادم واحد):**

```bash
cd server
npm install
cp ../.env.example ../.env   # اختياري
npm start                    # http://localhost:8787
```

الخادم يخدم الموقع ويضبط `site.config.js` تلقائياً حتى غرف اللعب تشتغل عبر نفس الرابط (`/ws`).
لتجربة جهازين بنفس الشبكة: افتحوا `http://<عنوان-الجهاز>:8787` من الجهاز الثاني.
للعب من أماكن مختلفة لازم ينشر الخادم على استضافة تدعم WebSocket (مثل Render أو Fly.io أو Railway أو أي VPS) وراه HTTPS.

**الموقع وحده (استضافة ثابتة مثل GitHub Pages):**
افتحوا `index.html` من أي خادم ثابت. إذا تريدون اللعب عن بعد عبر خادمكم، عدّلوا `site.config.js`:

```js
window.KY_CONFIG = { relayUrl: "wss://your-relay.example.com/ws" };
```

إذا `relayUrl` فارغ، اللعب عن بعد يستعمل PeerJS (اتصال مباشر بين الجهازين عبر خادم PeerJS العام المجاني). هذا الطريق يعتمد على خدمة خارجية وقد يفشل خلف بعض الشبكات.

### النشر

- **Render.com:** ملف `render.yaml` جاهز (New → Blueprint → هذا المستودع). يعطيكم رابط HTTPS واحد للموقع واللعب.
- **Docker** (Fly.io، Railway، أي VPS): `docker build -t khy . && docker run -p 8787:8787 khy`
- الخطة المجانية ببعض الاستضافات «تنام» إذا ما أحد استعملها، فأول فتح ياخذ ثواني.

### إعدادات الخادم

بملف `.env` (انظر `.env.example`): المنفذ، المواقع المسموحة (`ALLOWED_ORIGINS`)، عمر الغرفة، ومدة حجز مقعد اللاعب المنقطع. ماكو مفاتيح أو أسرار.
الغرف تنحفظ بذاكرة الخادم؛ إعادة تشغيل الخادم تنهي الغرف المفتوحة.

## الاختبارات

```bash
npm test                     # اختبارات خادم الغرف: إنشاء، انضمام، رمز غلط، غرفة مليانة، رجوع لنفس المقعد، انتهاء الغرفة
npm i && npm start           # بنافذة ثانية: تشغيل الخادم على 8787
npm run test:e2e             # اختبارات المتصفح (Playwright): كل المسارات على كمبيوتر وهاتف،
                             # المهمة الرئيسية كاملة، لعب من متصفحين منفصلين، وحكاية مشتركة
```

## شنو بالعالم

- **خريطة متفرعة** فوق لوحة القلعة: 20 مكان، 5 بوابات رئيسية (غابة أيلاف، حكاياتنا، قصر الأزياء، دفترنا، ساحة الاستكشاف)، وأماكن جانبية تنفتح بمفاتيح وألغاز ومساعدة الشخصيات، وكل قفل إله أكثر من طريق.
- **مهمة رئيسية** «ساعة الخريف» و7 مهمات جانبية، دفتر مهام، خريطة حكاية مصغرة، وعلامات «!» «؟» «✦».
- **شخصيات ثانوية أصلية**: العم سعدون، الخالة نرجس، أم الحكايات، زعفرانة، و«رسول» الطير الورقي — ويا أيلاف وجعموص وسومو.
- **حكاياتنا**: 5 حكايات × 3 فصول، بكل حكاية 3 اختيارات ومسارين ونهايتين، والاختيارات تتذكرها الحكايات الثانية.
- **ألعاب**: 9 ثنائية تنلعب على نفس الجهاز أو من جهازين + عرض أزياء مشترك + رسم مشترك + حكاية مشتركة، و9 ألعاب فردية بغابة أيلاف + صندوق النكت.

## بنية المشروع

| الملف | المحتوى |
|---|---|
| `index.html` | الهيكل والشريط العلوي |
| `assets/world_autumn_castle.png`, `assets/khabbab_yaqeen_characters.png` | الصورتان الأصليتان كما هما (نفس الملفين) |
| `assets/*.webp` | صور الموقع القديم: أيلاف، الغابة، وقصاصتا خباب ويقين للتحريك |
| `css/elaf.css` | أنماط وحركة عالم أيلاف الأصلية |
| `css/castle.css`, `css/world.css` | طبقة الخريف، الخريطة، الغرف، الحكايات |
| `js/config.js` | الأسماء والرسائل والنكت (عدّلوها هنا) |
| `js/world.js` | خريطة العالم، المسارات والأقفال، المهمات، دفتر المهام، خريطة الحكاية، المقدمة |
| `js/rooms.js` | الغرف والأماكن الجانبية وألغازها والنهاية |
| `js/tales.js` | حكاياتنا: 5 حكايات متفرعة |
| `js/palace.js` | قصر الأزياء وتحديات الستايلست والمسرح |
| `js/elaf-forest.js` | غابة أيلاف وألعابها الأصلية |
| `js/duo-kit.js`, `js/duo-games.js` | إطار الألعاب الثنائية و9 ألعاب |
| `js/party.js` | طبقة الاتصال (خادم WebSocket ← غرف Claude ← PeerJS) |
| `server/relay.mjs` | خادم الغرف |

## الخصوصية

كل التقدّم والمذكرات والرسومات تنحفظ بمتصفح الجهاز فقط (localStorage). اللعب عن بعد يمرر الاسم المستعار وحركات اللعب بين الجهازين بدون حفظها. ماكو حسابات ولا إعلانات ولا مشتريات.
