# مغامرات خباب ويقين

لعبة مستقلة بقلعة خريفية: مقدمة سينمائية، خريطة ورقية هادئة متفرعة من «ساحة ساعة القلعة»، سِراج اليرّاعة الميكانيكية دليل الممرات، حكايات تنلعب باختيارات تغيّر الطريق، قصر أزياء، غرفة خباب ويقين، وألعاب ثنائية تنلعب من جهازين.

عالم أيلاف القديم محفوظ كصفحة منفصلة (`elaf.html`) بحفظ خاص بيه، واللعبة ما تربط عليه ولا تذكره.

## التشغيل

الموقع ملفات ثابتة (HTML/CSS/JS) بدون خطوة بناء.

**أسهل طريقة (الموقع + اللعب عن بعد بخادم واحد):**

```bash
cd server
npm install
cp ../.env.example ../.env   # اختياري
npm start                    # http://localhost:8787
```

الخادم يخدم الموقع ويضبط `site.config.js` تلقائياً حتى غرف اللعب تشتغل عبر نفس الرابط (`/ws`).
لتجربة جهازين بنفس الشبكة: افتحوا `http://<عنوان-الجهاز>:8787` من الجهاز الثاني.
للعب من أماكن مختلفة لازم ينشر الخادم على استضافة تدعم WebSocket (مثل Render أو Fly.io أو Railway أو أي VPS) وراه HTTPS.

**الموقع وحده (استضافة ثابتة مثل Vercel أو GitHub Pages):**
افتحوا `index.html` من أي خادم ثابت. إذا تريدون اللعب عن بعد عبر خادمكم، عدّلوا `site.config.js`:

```js
window.KY_CONFIG = { relayUrl: "wss://your-relay.example.com/ws" };
```

إذا `relayUrl` فارغ، اللعب عن بعد يستعمل PeerJS (اتصال مباشر بين الجهازين عبر خادم PeerJS العام المجاني). هذا الطريق يعتمد على خدمة خارجية وقد يفشل خلف بعض الشبكات. النسخة المنشورة على Vercel (ملفات ثابتة) تستعمل هذا الطريق.

**شلون تعزمون صديق:** زر «صديق» فوق ← اكتبوا اسم مستعار واختاروا شخصية ← «أنشئ غرفة» ← انسخوا الرابط ودزّوه (أو قولوا الرمز من 5 حروف). الصديق يفتح الرابط من جهازه ويضغط «ادخل»، وبعدين الاثنين يضغطون «جاهز» وصاحب الغرفة يختار اللعبة.

### النشر

- **Render.com:** ملف `render.yaml` جاهز (New → Blueprint → هذا المستودع). يعطيكم رابط HTTPS واحد للموقع واللعب.
- **Docker** (Fly.io، Railway، أي VPS): `docker build -t khy . && docker run -p 8787:8787 khy`
- الخطة المجانية ببعض الاستضافات «تنام» إذا ما أحد استعملها، فأول فتح ياخذ ثواني.

### إعدادات الخادم

بملف `.env` (انظر `.env.example`): المنفذ، المواقع المسموحة (`ALLOWED_ORIGINS`)، عمر الغرفة، ومدة حجز مقعد اللاعب المنقطع. ماكو مفاتيح أو أسرار.
الغرف تنحفظ بذاكرة الخادم؛ إعادة تشغيل الخادم تنهي الغرف المفتوحة.

## الاختبارات

```bash
npm test                     # اختبارات خادم الغرف: إنشاء، انضمام، رمز غلط، غرفة مليانة، رجوع لنفس المقعد، انتهاء الغرفة
npm i && npm start           # بنافذة ثانية: تشغيل الخادم على 8787
npm run test:e2e             # اختبارات المتصفح (Playwright): كل المسارات على كمبيوتر وهاتف،
                             # المهمة الرئيسية كاملة، لعب من متصفحين منفصلين، وحكاية مشتركة
node tests/touch.mjs         # لمس الهاتف (محاكاة Chromium، مو Safari حقيقي)
```

## شنو بالعالم

- **مقدمة سينمائية**: ضو سِراج بالظلمة، لوحة القلعة الأصلية تنكشف، خباب يركض ويقين تلتفت وترمش، وبعدها العنوان. زر «تخطّي»، تنعرض كاملة أول مرة بس، وتنعاد من القائمة، وتنعرض ثابتة إذا الجهاز طالب حركة أقل.
- **خريطة ورقية هادئة** (رسم، مو لوحة القلعة): «ساحة ساعة القلعة» بالنص وتسع مناطق — ورشة الساعات، المرصد، الدفيئة، قصر الأزياء، غرفة خباب ويقين، محطة القطار، الغابة، الحديقة القديمة، المكتبة. الضغط على منطقة يقرّب الكاميرا وتطلع ورقة سفلية بأماكنها.
- **أماكن جانبية**: غرفة التروس، غرفة الفوانيس، سطح القلعة، الرصيف القديم، نفق الأوراق، الحديقة المخفية، ممر الكتب الخضراء، والممر خلف المكتبة. كل قفل إله أكثر من طريق، وبعض المفاتيح تجي من الألعاب (مفتاح السياج من المتاهة، الضو من صيد الفوانيس، قطعة تذكرة من القطار).
- **مهمة رئيسية** «ساعة الخريف» و8 مهمات جانبية، دفتر مهام بيه الطرق المقفولة وشروطها، خريطة صغيرة، وعلامات «!» «؟» «✦».
- **شخصيات ثانوية أصلية تتكرر**: سِراج (دليل الممرات، يطلع بس إذا عنده تلميح)، العم سعدون، الخالة نرجس، أم الحكايات، زعفرانة، ريحانة الخيّاطة، شوكة القنفذ، و«رسول» الطير الورقي.
- **حكاياتنا**: 5 حكايات × 3 فصول، بكل حكاية 3 اختيارات ومسارين ونهايتين، والاختيارات تتذكرها الحكايات الثانية.
- **ألعاب**: 9 ثنائية تنلعب على نفس الجهاز أو من جهازين + عرض أزياء مشترك + رسم مشترك + حكاية مشتركة، وألغاز بكل غرفة (تروس، فوانيس، نجوم، أوراق، إشارات، ترتيب الغرفة…).

## الخصوصية

كل التقدّم والمذكرات والرسومات تنحفظ بمتصفح الجهاز فقط (localStorage). اللعب عن بعد يمرر الاسم المستعار وحركات اللعب بين الجهازين بدون حفظها. ماكو حسابات ولا إعلانات ولا مشتريات.
